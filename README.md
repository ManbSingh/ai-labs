# AI Labs Documentation

## Project Overview
This repository hosts various projects that leverage AI technologies for practical applications. Key projects include a predictive maintenance assistant and a chatbot that explores Canadian landmarks.

## Installation Instructions
To set up the projects locally, follow these steps:
1. Clone the repository: 
   ```bash
   git clone https://github.com/ManbSingh/ai-labs.git
   cd ai-labs
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```

## Architecture
The architecture consists of modular components that can be independently tested and deployed. Each project follows the MVC paradigm to separate concerns effectively.

## Tech Stack
- Python 
- Node.js 
- TensorFlow 
- Flask
- React

## Project Descriptions
### Predictive Maintenance Assistant
This project aims to predict when maintenance should be performed on machinery to prevent unexpected failures. Utilizing machine learning algorithms trained on historical data, it provides actionable insights that can help in scheduling maintenance tasks effectively.

### RAG Chatbot Discover Canada
This project features a conversational chatbot that guides users through various Canadian landmarks. It uses a retrieval-augmented generation (RAG) model to provide informative dialogs and enhances user experience by delivering relevant information about each location, including history, attractions, and visitor tips.
